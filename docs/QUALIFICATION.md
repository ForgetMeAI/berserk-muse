# Проверки и ограничения Berserk

Локальная квалификация перед публикацией, 2026-10-21: **512/512** тестов на macOS, Node 22.23.3 и Node 26.0.0. Оба процесса завершились с кодом 0, без пропусков и отмен. Хеши проверяемого набора совпали до и после. [Исторический манифест тестов](verification-2026-10-21.json). Результаты текущих коммитов — в [GitHub Actions](https://github.com/ForgetMeAI/berserk-muse/actions).

На принадлежащих владельцу тестовых аккаунтах Luuvan и Generator.email подтверждены получение свежего Muse-кода, автоматический ввод и сохранение сессии. Для Generator дополнительно подтверждены native health-check, чтение баланса и сохранение доступа после штатного перезапуска без постоянного окна Muse. В одном другом тестовом ящике свежие письма не наблюдались при Muse HTTP 201; причина недоставки не установлена, ручной fallback сохранён.

При отсутствии адреса в шапке Generator адаптер проверяет единственный контекст ящика/ID сообщения, объявленный сервером в финальном HTTPS-ответе. Поле recipientSource=mailbox_context явно отличает это от буквального To. Чужие/неоднозначные адреса и некорректный/просроченный контекст отклоняются. Секундная точность timestamps может консервативно исключить новое письмо той же секунды; временная граница не ослаблена без baseline ID.

## Исторические проверки

- Более ранний архив прошёл 416/416 тестов на Linux x64, Node 22.23.3, и запуск/панель/остановку пустого сервиса. Поздние изменения отдельно на Linux не запускались. WSL2 выбран способом запуска на Windows, но реальной WSL2-квалификации ещё нет.
- Claude Code 2.1.303 и Hermes 0.16.0 прошли реальную изолированную coding-задачу через Muse на macOS: падающий тест, исправление, зелёные проверки, proof. Это историческое свидетельство прежних исходников, не повторный live-gate текущих байтов. OpenCode также проходил отдельный исторический coding gate.
- Опубликованный CI проверяет Ubuntu/macOS с Node 22/26, затем запуск, status и остановку пустого сервиса. Первый прогон выявил зависимость unit-теста от браузера, установленного на runner: Linux корректно обнаружил Chrome, а тест ожидал Chrome channel вместо обнаруженного пути. Fixture теперь явно задаёт выбор браузера; отдельный тест проверяет передачу явного executablePath. Это изменение тестов, production-транспорт не менялся.

## Практические границы

Проект экспериментальный, не официальный Muse API. Баланс берётся из читаемой подписи Muse; K/M/B помечаются приблизительными. Локальный usage — оценка, а не биллинг. Неизвестные остатки не складываются в известную сумму.

Сохранённые сессии и почтовые ссылки предназначены только для локального каталога .state; они не входят в этот репозиторий. CAPTCHA, Terms и запросы разрешений остаются пользователю. Gmail/Outlook требуют отдельного scoped OAuth либо ручного входа.

Независимое локальное ревью выполнено. Полный финальный аудит Claude Opus не получен; положительное ревью не имитируется.
