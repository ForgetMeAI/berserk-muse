# Разработка

Нужен Node.js 22+ и npm. Установите зависимости командой npm ci --ignore-scripts, затем выполните npm test. Для проверки панели: npm run launch, npm run panel, npm run stop.

Новые изменения оформляйте в существующем стиле .mjs, с осмысленными тестами изменённого поведения. Не включайте .state, почтовые ссылки, cookies, токены, профили браузера и журналы реальных входов. Тесты должны использовать синтетические данные.

Live-проверки требуют собственного аккаунта и отдельного осознанного запуска. Они не являются частью обычного npm test или CI. В баг-репорте укажите ОС, версию Node и фиксированный код ошибки; секреты и письма не прикладывайте.
