# История изменений

## 0.1.0 — 2026-10-21

- Локальный OpenAI Chat Completions и Anthropic Messages API для Muse.
- Запуск Claude Code, Hermes и OpenCode с отдельными профилями клиентов.
- Сохранённые аккаунты и прямой HTTP/WebSocket-транспорт без постоянного браузера.
- Построчный импорт email | mail URL; Generator.email и Luuvan, ручной fallback.
- Локальная панель, фоновые задачи, SSE, баланс Muse и сводная статистика.
- Ссылка на @forgetshop_bot под заголовком, подпись @forgetmeai.
- Node 22+, macOS/Linux; Windows через WSL2. Ограничения проверок — в docs/QUALIFICATION.md.

Экспериментальная совместимость, не официальный Muse API.
