# Сообщения о проблемах безопасности

Не публикуйте в Issues реальные сессии, почтовые ссылки, cookies, OTP, HAR или содержимое .state. Для воспроизведения используйте синтетические данные и обезличенные коды ошибок.

После создания GitHub-репозитория приватный отчёт можно отправить через вкладку Security, если владелец включит private vulnerability reporting. До этого договоритесь с владельцем о приватном канале, не прикладывая секреты к публичному обращению.

Berserk слушает loopback-интерфейс. Панель не требует пользовательского входа и предназначена для локального устройства; её не следует публиковать через внешний reverse proxy.
